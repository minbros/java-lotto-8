# 로또
## 프로젝트 구조
```
`-- java
    `-- lotto
        |-- Application.java
        |-- domain
        |-- dto
        |-- exception
        |-- pipeline
        |   `-- stage
        |-- util
        `-- view
```
레이어드 아키텍처와 파이프라인 아키텍처를 적용했습니다.<br>

레이어드 아키텍처를 통해 View - Pipeline(Controller) - Domain의 세 계층으로 분리되어 있습니다.<br>

파이프라인 아키텍처를 통해 컨트롤러 흐름이 다음과 같이 순차적으로 진행됩니다. `stage` 패키지가 각각의 흐름을 담당합니다.
> 구매 금액 입력 - 로또 생성 및 출력 - 당첨 번호 입력 - 당첨 결과 반환 - 결과 출력

## 기능 구현 사항
### 구매 금액 입력 (Void -> Integer)
- 구매 금액을 입력받아 `Integer` 타입으로 파싱합니다.
- 구매 금액에 대한 기본 검증을 수행합니다. (구매 금액이 자연수인지 여부)
- 파싱한 구매 금액을 반환합니다.

### 로또 생성 및 출력 (Integer -> List\<Lotto\>)
- 구매 금액이 적합한지 검증합니다.
  - 1,000원 단위에 맞는지 
  - 설정한 최대 금액(1,000,000원) 이하인지 
- 검증 후 해당되는 개수만큼 로또를 생성합니다.
- 생성된 로또를 콘솔에 출력하고 반환합니다.

### 당첨 번호 입력 (List\<Lotto\> -> LottoData)
- 당첨 번호와 보너스 번호를 입력받아 `WinningLotto` 타입으로 변환합니다.
- 생성된 로또와 `WinningLotto`를 `LottoData`에 저장합니다.
- 저장한 `LottoData`를 반환합니다.

### 당첨 결과 반환 (LottoData -> LottoResult)
- 'LottoData'를 통해 당첨 결과와 수익률을 계산합니다.
- 당첨 결과와 수익률을 `LottoResult`에 저장합니다.
- 저장한 `LottoResult`를 반환합니다.

### 결과 출력
- `main` 함수의 마지막에 실행됩니다.
- 반환받은 `LottoResult`를 출력합니다.

## 예외 구현 사항
- 당첨 번호를 입력받을 때 `1, 2, 3, 4, 5, 6`과 같이 공백도 허용됩니다.
- 당첨 번호를 입력받을 때 `1,,2,,3,,4,,5,,6`, `,1, 2, 3, 4, 5, 6`, `1, 2, 3, 4, 5, 6,`과 같이 구분자 형식이 잘못되면 에러가 발생합니다.
- 당첨 번호 6개와 보너스 번호 1개는 모두 서로 중복될 수 없게 설정했습니다.
- 구매 가능한 최대 금액을 1,000,000원으로 지정했습니다.
